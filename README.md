# 🚀 Proyecto: Login con FastAPI, MySQL y Docker

Este proyecto implementa una aplicación web sencilla con **FastAPI** y **MySQL**, desplegada mediante **Docker**.  
Permite iniciar sesión con credenciales almacenadas en la base de datos y, si el acceso es correcto, muestra una página con marcas de coches europeas.

---

## 📦 Requisitos previos

- Tener instalado **Docker** y **Docker Compose**.
- Clonar este repositorio:

```bash
git clone https://github.com/Daritxe2/app_login_david.git
cd app_login_david
